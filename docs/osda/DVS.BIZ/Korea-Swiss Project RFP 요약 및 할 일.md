## 한눈에 보기

- 한국 KIAT와 스위스 Innosuisse가 공동 운영하는 양자 R&D 지원 사업
- 목표: 한국과 스위스 양국에서 시장성이 있는 제품, 기술 기반 서비스 또는 공정의 상용화 준비
- 지원 분야는 전 과학기술 분야이며, 아래 분야를 특히 강조
  - Biotech, Medtech
  - Digitalisation, Industry 4.0, IoT, AI
  - Additive manufacturing
  - Smart Materials, Innovative Surfaces
  - AR, VR
  - Hydrogen Technologies
  - Renewable Energy, Batteries

## 필수 자격 조건

- 과제 기간: **18~36개월**
- 컨소시엄 필수 구성
  - 한국 기업 최소 1개
  - 스위스 기업 최소 1개
  - 한국 또는 스위스 연구기관 최소 1개
  - 예외: 스위스 신청자가 시장 진입 전이며 직원 수 50명 미만인 단일 스타트업인 경우 연구기관 참여 면제
- 한국 기관과 스위스 기관은 계열 관계가 없어야 함
- 국가별 투입 인력 비율: 한 국가가 전체 person-month의 **30% 미만 또는 70% 초과**가 되면 안 됨
  - 1 person-month = 154시간
- 초안 Consortium Agreement(CA) 제출 필수
  - Intellectual Property Rights(IPR) 내용 포함
- 자체 부담금 조달 능력을 증빙하는 재무 자료 제출 필수
- 각 국가에서 발생한 비용만 해당 국가 기관이 지원하며 국가 간 교차 지원은 불가
- 마감 후 오류 수정 불가. 부적격 기관이 포함되면 제안서 전체가 탈락할 수 있음

## 한국 측 지원 및 제출

- 한국 참여자는 KIAT 과제관리시스템 [K-PASS](http://www.k-pass.kr)에서 신청
- **국문 및 영문 신청서** 제출 필요
- 세부 제출 서류와 지원 비율은 한국어 공고문을 반드시 별도로 확인
- 한국 측 참여 가능 기관
  - 기업부설연구소를 보유한 한국 기업
  - 한국 연구기관
  - 대학
- 한국 측 지원 비율

| 기관 유형 | 정부 지원 비율 |
| --- | --- |
| 연구기관 | 적격 비용의 100% |
| 소기업 | 최대 66.6% |
| 중기업 | 최대 50% |
| 대기업 | 최대 33.3% |

- 민간 부담금은 현금 및 현물로 구성

## 스위스 측 지원 및 제출

- 스위스 참여자는 [Innosuisse Innolink](https://innolink.innosuisse.ch)에서 신청
- 한국 측 KIAT 신청서, 스위스 측 신청서, 공동 제안서의 **과제명이 모두 동일**해야 함
- Innolink의 Introduction에서 Bilateral Call 국가를 `South Korea`로 선택
- 공동 제안서와 CA 초안을 업로드
- 스위스 implementation partner는 전체 스위스 과제비의 최소 30%를 자체 부담
- 직원 수 250명 미만의 스위스 implementation partner는 재무 능력 증빙 필요

### 스위스 측 재무 서류

CHF 500,000 미만 요청 시:

- [ ] 최근 2개 사업연도 또는 설립 이후의 서명된 손익계산서 및 대차대조표
- [ ] Financial Table
- [ ] 전년도 말 및 최근 월말 은행 계좌 명세서
- [ ] 최종 감사 서신(해당 시)
- [ ] 최신 채무집행 추출 문서 Betreibungsauszug(해당 시)

CHF 500,000 이상 요청 시 위 서류에 추가:

- [ ] 5개년 재무 전망
- [ ] 최신 주주명부
- [ ] 조직도
- [ ] 대출 계약서 사본
- [ ] 과제 부담금 조달 방법과 현황에 대한 자기 선언서

## 평가 기준

### 공통 핵심

- 양국 기관이 각각 평가하고 공동 순위를 정함
- 한국과 스위스 양쪽 평가를 모두 통과해야 지원 가능
- 예산 범위 내에서 공동 순위 순서대로 지원

### 제안서에 명확히 보여줘야 할 내용

- 명확하고 구체적인 과제 정의
- 정량화 가능한 목표와 마일스톤
- 접근 방법과 자원 배분의 타당성
- 국제 최고 수준 대비 차별화되는 혁신성
- 양국 협력으로 얻는 구체적인 부가가치
- 컨소시엄 구성원의 상호보완성
- 과제 종료 후에도 이어질 협력 기반
- 제품, 공정 또는 서비스의 시장 진입 및 사업화 계획
- 신규 가치사슬 창출 또는 기존 가치사슬 편입 계획
- 사회경제적 파급효과
- 예산 구성의 적절성

## 해야 할 일

### 즉시 확인

- [ ] 한국어 통합 시행계획 공고문을 읽고 한국 측 세부 제출 서류, 민간 부담금 비율, 기업 규모 기준 확인
- [ ] 제출 담당자와 내부 의사결정권자 지정
- [ ] 한국 기업의 기업부설연구소 등록 상태 확인
- [ ] 스위스 파트너, 연구기관 포함 여부와 각 기관의 자격 확인
- [ ] 한국 및 스위스 참여기관 간 계열 관계가 없는지 확인

### 컨소시엄 및 과제 설계

- [ ] 과제 기간을 18~36개월 범위로 확정
- [ ] 전체 work package와 기관별 역할 정의
- [ ] 국가별 person-month를 산정하고 한국:스위스 비율이 30:70~70:30인지 확인
- [ ] 개발 목표, 정량 KPI, 마일스톤 작성
- [ ] 국제 최고 수준 대비 기술 차별점 작성
- [ ] 양국 협력이 필요한 이유와 각 파트너의 상호보완성 작성
- [ ] 시장 진입 전략, 고객, 경쟁력, 사업화 일정 작성

### 문서 준비

- [ ] 국문 연구개발계획서 작성
- [ ] 영문 공동 제안서 작성
- [ ] KIAT와 Innosuisse 제출본의 영문 과제명 통일
- [ ] IPR 내용을 포함한 CA 초안 작성
- [ ] 기관별 예산과 국가별 적격 비용 검토
- [ ] 한국 측 필수 첨부 서류 준비
- [ ] 스위스 측 요청 금액에 맞는 재무 서류 준비
- [ ] 개인정보 및 기밀정보의 양 기관 공유 범위 내부 확인

### 제출 전 점검

- [ ] K-PASS에 국문 및 영문 신청서 등록
- [ ] 스위스 파트너가 Innolink에서 `South Korea`를 선택했는지 확인
- [ ] 양국 포털과 공동 제안서의 과제명이 완전히 동일한지 확인
- [ ] CA 초안이 양쪽 제출본에 포함됐는지 확인
- [ ] 부적격 기관, 누락 서류, 예산 오류, person-month 비율 오류 최종 점검
- [ ] **2026-06-30 EOD 이전 제출 완료**
